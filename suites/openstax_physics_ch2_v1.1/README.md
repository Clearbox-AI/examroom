# openstax_physics_ch2

46 numeric items from the solved (odd-numbered) end-of-chapter
exercises of OpenStax College Physics 2e, chapter 2.  Problems that
depend on a figure, sketch, or graph are excluded, as are answers that do
not parse as a single physical quantity.  Multi-part problems yield one
item per part; the prompt names the part and the expected unit.

Scoring compares magnitudes (the prompts don't pin a sign convention) with a
tolerance of max(half a unit in the book answer's last significant digit, 0.5%),
so an answer correctly rounded to fewer digits than the reference still passes.

Problems and answers derived from OpenStax College Physics 2e, openstax.org/details/books/college-physics-2e, © Rice University, CC BY-NC-SA 4.0.

Authored by `scripts/author_openstax_physics.py`; re-running it refetches the live pages and may
differ if OpenStax edits the book — treat the frozen version as canonical.
